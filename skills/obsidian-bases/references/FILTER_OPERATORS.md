# Filter Operators

Filters in `.base` files support the following operators.

| Operator | Description |
|----------|-------------|
| `==` | equals |
| `!=` | not equal |
| `>` | greater than |
| `<` | less than |
| `>=` | greater than or equal |
| `<=` | less than or equal |
| `&&` | logical and |
| `\|\|` | logical or |
| <code>!</code> | logical not |

Use these operators inside `filters` expressions, either as single strings or within `and`/`or`/`not` lists. See `../SKILL.md` for filter structure examples.
